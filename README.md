# JSAB Beat Studio

Motor coreográfico reactivo al ritmo inspirado en *Just Shapes & Beats*, diseñado para crear videos musicales, Shorts y Reels con jefes personalizados (PNG / GIF animado).

## 🌐 Demo en Vivo (GitHub Pages)
👉 **[https://tolgrim-arch.github.io/jsab-beat-studio/](https://tolgrim-arch.github.io/jsab-beat-studio/)**

## ✨ Características Principales
- **Análisis Musical Automático:** Detección de BPM, drops, secciones y arquetipos.
- **Jefes Personalizados:** Sube PNG/GIFs o busca en GIPHY con animación sincronizada al BPM y **Auto-Paleta**.
- **YouTube / Shorts Creator Studio:**
  - Formatos **16:9 (720p / 1080p)**, **9:16 (720p / 1080p Shorts)** y **1:1**.
  - **Recorte de Clip (In/Out)** para Shorts.
  - **Overlays de Retención:** Tarjeta de Comentario, Banner *VS BOSS*, Barra HP + Contador *Near-Miss*, y Pantalla CTA Final.
  - **Generador de Miniatura PNG** y **Cola de Render en Masa (Batch Queue)**.
  - **Presets de 1 Clic** (incluyendo *Modo Puro* con todo deshabilitado) y exportar/importar JSON.
- **4 Fondos de Bioma Reactivos:** *Seismic*, *Tunnel*, *Perspective* y *Vortex*.
